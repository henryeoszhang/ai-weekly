# AI WEEKLY

個人制作の日本語AI週報（試行版）。AIを用いて公開資料を整理・要約し、経営・管理職、一般社員、開発者向けの3版に編集しています。各社・団体の公式媒体ではありません。

## 掲載構成

- `index.html`: 最新号への入口と発行一覧
- `issues/YYYY-MM-DD/index.html`: 各号の固定ページ
- `issues/YYYY-MM-DD/executive.html`: 経営・管理職版
- `issues/YYYY-MM-DD/employee.html`: 一般社員版
- `issues/YYYY-MM-DD/developer.html`: 開発者版

各版は自立した静的HTMLです。ビルド、JavaScript、外部フォント、解析タグ、第三者の埋め込みは不要です。`.nojekyll` は静的ファイルをそのまま配信するための設定です。

## 次号を追加する

1. 新しい発行日で `issues/YYYY-MM-DD/` を作り、3版と号の `index.html` を追加します。
2. 各号の相対リンク、20件のニュース、コラム、出典、日付・対象期間・留保を確認します。
3. トップ `index.html` の最新号リンクを新しい号へ更新し、発行一覧の先頭に新しい号を追加します。以前の号とそのURLは残します。
4. 公開前に内容・個人情報・権利・PC/スマートフォン表示・印刷を点検し、GitHub Pagesの配信完了後に最新号と過去号のリンクを確認します。

GitHub Pagesでは `main` ブランチの `/ (root)` を配信元に指定します。生成ツールや外部サービスへの新たな登録は不要です。

## 編集と訂正

各版の「選び方と順位の読み方」「出典と編集方針」に評価基準と確認範囲を記載しています。点数は編集上の評価であり、性能や将来の成果を保証しません。製品の動作試験や研究の独立追試は行っていません。

同じ号を訂正する場合は日付の固定URLを保ち、影響する記事に訂正日と変更内容を記載します。重要な事実を、説明なしに書き換えない運用とします。引用先・参照先の文章や資料の権利は各権利者に帰属します。
